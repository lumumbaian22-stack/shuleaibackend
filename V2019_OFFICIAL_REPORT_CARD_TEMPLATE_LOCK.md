# ShuleAI v2019 Official Report Card Template Lock

This patch locks the chosen **Official Classic** report-card design into the real system.

## What changed

- Draft preview and published/final reports now use the same Official Classic report-card design.
- Draft reports show a draft-only status label; published reports show official status.
- Report cards use the school theme colors when set.
- Report cards use school logo as header/logo/watermark when available.
- If no school logo exists, the admin can choose school initials or the official ShuleAI logo as fallback.
- School motto, registration number, postal address, phone, email, website, county/location, and curriculum label are controlled inside the existing Academic & Report Card Settings area.
- Student photo appears when available and enabled; otherwise initials are shown.
- The PDF report-card route uses the same Official Classic layout family as the browser/print preview.

## Logic rule

One report-card design is used for both draft and final. Only the report mode changes the status label and access rules.
